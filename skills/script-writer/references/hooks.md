# Hook library

Structures, not scripts. Swap in the persona's exact words (language bank) and real numbers (proof bank).
Examples are illustrative; never publish a number you can't back. pt = pt-BR, es = neutral/LATAM unless noted.

How to pick: match the **awareness level** (unaware → story/curiosity; problem-aware → pain/mistake;
solution-aware → how-to/comparison; product-aware → proof/offer) and the **format** (video hooks need a visual too).

## Visual hooks for video (pair with any line above)
Result first (show the after, then rewind) · object in motion toward camera · text on a surprising prop (sticky note,
whiteboard) · split-screen before/after · screen recording zoomed on the number · "green screen" over a comment/
review (blur names) · hand enters frame and does the action · walking-and-talking start mid-sentence.

## Rules
- Hooks promise; the body must deliver within the first half.
- Specific > clever: numbers, roles, times of day, exact phrases.
- Avoid: "Did you know…", "In today's video…", "Hey guys", clickbait the content doesn't pay off.
- Localise, don't translate: Brazilian "flopar", "gancho", "isca digital"; Spain "guay", "móvil"; LATAM "celular",
  "chévere" (country-specific) — only if `voice.md` allows slang.
